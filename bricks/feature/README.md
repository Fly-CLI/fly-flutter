# feature

Fly foundation feature scaffolding brick for generating feature screens and view models.

## Description

This brick generates feature scaffolding for existing Fly projects, including:

- Feature screens with MVVM structure
- View models
- Tests
- Documentation

## Usage

This brick is typically used via the Fly CLI:

```bash
fly generate screen my_screen --feature=home --template=fly_foundation
```

Variables are passed programmatically by the Fly CLI orchestrator. For manual usage, see the [Fly CLI documentation](https://github.com/fly-cli/fly).
