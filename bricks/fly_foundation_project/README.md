# fly_foundation_project

Fly foundation project scaffolding brick for generating complete Flutter applications.

## Description

This brick generates a complete Flutter project structure using the Fly foundation architecture, including:

- Base foundation classes (MVVM pattern)
- Navigation setup
- Theme configuration
- Localization support
- Project structure following Fly best practices

## Usage

This brick is typically used via the Fly CLI:

```bash
fly generate project my_app --template=fly_foundation
```

Variables are passed programmatically by the Fly CLI orchestrator. For manual usage, see the [Fly CLI documentation](https://github.com/fly-cli/fly).
